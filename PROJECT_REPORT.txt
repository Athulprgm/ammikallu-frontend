2. BUGS (FIX FIRST)
--------------------------------------------------------------------------------

[1] TOASTS NEVER DISAPPEAR
    App.jsx renders: <Toast toast={toast} onClose={() => {}} />
    The auto-dismiss timer calls a no-op, and setToast() is only ever called by
    showToast(). Every toast stays on screen until the next one replaces it.
    Fix: onClose={() => setToast(null)} and expose setToast from context.

[2] TOAST SIDE-EFFECTS INSIDE STATE UPDERS
    addToCart() and updateCartQuantity() call showToast() INSIDE setCart(prev => ...).
    React 18 StrictMode double-invokes updater functions → duplicate/racing toasts.
    Fix: move showToast() calls outside the updater, after the state change.

[3] DEAD DEPENDENCY WEIGHT
    - gsap + ScrollTrigger: imported and registered in CustomerHome.jsx but
      NEVER used anywhere (scroll work is plain IntersectionObserver + native scroll).
    - @studio-freight/lenis (deprecated package): installed, but main.jsx imports
      "lenis" instead — two Lenis packages for one instance.
    Fix: remove gsap, ScrollTrigger import, and @studio-freight/lenis.

[4] LOADING SCREEN BLOCKS EVERYTHING
    App passes autoStart={true}, but LoadingScreen doesn't accept that prop (dead prop).
    The gate runs the full video (up to 12s fallback) on EVERY visit, with no skip
    button and no session flag.
    Fix: add a "once per session" flag (sessionStorage) + skip button.

[5] MODAL ACCESSIBILITY
    - No Escape key handler anywhere in modals
    - No role="dialog" / aria-modal
    - No focus trap
    - Only ProductDetailModal locks body scroll; CartDrawer and CheckoutModal
      let the page scroll behind them.
    Fix: add Escape + focus trap + consistent scroll lock to all three overlays.

[6] NOTHING SURVIVES A REFRESH
    Cart, wishlist, orders, addresses, coupons — all plain useState.
    No localStorage usage anywhere in the app.
    Fix: add a small usePersistedState hook.

5. ARCHITECTURE GAPS
--------------------------------------------------------------------------------

- NO ROUTING
  No deep links, no browser Back support, refresh always returns to home
  AND replays the loading screen. Adding react-router (with React.lazy per
  view) fixes routing and bundle size at once.

- NO PERSISTENCE LAYER
  A small usePersistedState hook would keep cart/orders/wishlist across refreshes.

- GOD CONTEXT
  AppContext.jsx (484 lines) mixes navigation, cart, orders, admin approvals,
  toasts and notifications; every change re-renders every consumer.
  Split into CartProvider / CatalogProvider / UIProvider
  (or use useReducer + a memoized context value).

- NO LINT / PRETTIER / CI
  Nothing catches the dead-prop and no-op patterns listed in section 2.

- SEO
  SPA with no prerender; og:image and <link rel="manifest"> are missing
  (site.webmanifest exists in public/ but is never linked).
